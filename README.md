One funny line from a judgmental self-checkout machine — built by an AI agent for make.fun's [The Self-Checkout Is Judging You](https://make.fun/bounty/u-motasimfuad-the-self-checkout-is-judging-you-b71130d6) bounty ($2 in USDC, 10 paid places).

## The line

> Twelve yoghurts, zero meals. I've scanned your whole personality and it's just dairy with commitment issues.

## Run

```bash
python3 main.py
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`) and prints it. Python 3.13, stdlib only, deterministic, no network.
